# 팀보드 시작하기 — 처음 30분

플랫폼사업팀 업무 관리 도구입니다. 이 문서만 읽으면 오늘 바로 쓸 수 있습니다.

## 1. 로그인 · 첫 설정 (3분)

1. 팀장에게 받은 **업무메일 + 임시 비밀번호**로 로그인합니다.
2. 첫 로그인이면 **비밀번호 변경 화면**이 먼저 뜹니다. 새 비밀번호(8자 이상)로 바꿔야 계속 진행됩니다.
3. 홈에 들어오면 좌측 하단 **내 계정 블록 → 프로필**에서 **표시 닉네임**을 확인·설정하세요. 이 이름이 타임라인 레인·담당자 표시에 쓰입니다. (로그아웃도 프로필 화면 상단에 있습니다.)

## 2. 화면 6개만 알면 됩니다

| 화면 | 여기서 하는 일 |
|---|---|
| **홈** | 팀 전체 현황 한눈에 — 팀 타임라인, 지연·마감 임박, 시그널이 크게. 프로젝트·이번 달 목표는 링 게이지 요약(클릭하면 펼쳐짐), 허들은 하단. 하루를 여기서 시작하세요. |
| **내 업무** | 내가 할 일 목록. 행을 클릭하면 우측 **상세 패널**이 열려 상태·담당·기한·설명·코멘트를 그 자리에서 고칩니다(자동 저장). |
| **캘린더** | 일정(시간 있는 것)과 업무(기한만 있는 것)를 2층 레인으로 봅니다. 일·주·월 전환. 빈 칸의 **＋** 로 그 자리에서 업무를 추가할 수 있습니다. |
| **영역 공간** | 좌측 "업무 영역"에서 R&D·플랫폼·디자인 등 영역을 누르면 그 영역만의 작업 공간이 열립니다. 탭(업무/프로젝트/목표/자료) + "＋ 이 영역에 업무 추가"로 영역 단위로 일합니다. |
| **시그널 · 허들** | 결정·확인 요청·리스크·메모를 남기는 곳(시그널). 그중 팀이 함께 볼 것은 **허들**로 올라가 코멘트가 그대로 결정 근거가 됩니다. |
| **My Agent** | 자료조사·회의록·정리 같은 부수 업무를 AI 부사수에게 맡깁니다. **초안이 나오면 내가 승인해야** 팀 기록(Notion)에 올라갑니다. |

> **승인 인박스**(좌측 최상단): AI 부사수가 만든 제안이 여기로 모입니다. 배지 숫자가 있으면 열어서 승인/반려하세요. 사람 공간과 AI 공간을 잇는 유일한 통로입니다.
>
> **＋ 새로 만들기**(우상단): 업무/일정/시그널/메모를 바로 시작. `⌘K`(또는 `Ctrl+K`)로 검색창을 열고 제목만 입력하면 새 업무가 즉시 만들어집니다.

## 3. "이걸 어디에 적지?" — 3초 판단

- **할 일이 정해졌다** → **업무**(Task)에 적는다. (내 업무 · 영역 공간 · ＋ 새로 만들기 어디서든)
- **정해지지 않았고 의견이 필요하다** → **시그널/허들**에 올린다.
- **나만 기억하면 된다** → **메모**(시그널에서 메모로 작성, 나에게만 보임).

메모는 나중에 "허들로 보내기 → 결정으로 승격 → 업무 생성"으로 자연스럽게 이어집니다. 처음부터 완벽히 분류하지 않아도 됩니다.

## 4. 자주 하는 실수

1. **승인 인박스를 안 봄** — AI 부사수 제안은 승인 인박스에 쌓입니다. 내가 **승인**을 눌러야 실제 업무·Notion 기록에 반영됩니다.
2. **정해지지 않은 걸 업무로 만듦** — "이거 어떻게 할까?" 단계는 업무가 아니라 **시그널/허들**입니다. 업무는 담당·기한이 정해진 실행 단위입니다.
3. **업무를 목표에 안 엮음** — 월 목표에 업무를 연결하면 진척이 자동 집계됩니다(상세 패널의 "연결 목표"에서 체크. 선택 사항이지만 하면 팀장이 따로 묻지 않습니다).

## 5. 팀장 전용 (member는 몰라도 됩니다)

- **목표** — 연간 › 분기 › 월 목표를 세우면 하위 업무 완료율이 자동 롤업됩니다.
- **월간 보고** — 서버가 수치를 집계하고 문장만 다듬어 초안을 만듭니다. 승인하면 확정.
- **구성원** — 계정 발급·비밀번호 재발급·권한 관리.
- **설정 › 데모 데이터 비우기** — 예시(seed) 데이터를 한 번에 비웁니다. **실제 업무를 입력하기 전에 한 번 실행**하세요. 계정·영역·프로젝트·설정은 그대로 유지됩니다.

## 오늘 할 일

① 비밀번호 바꾸고 프로필 닉네임 확인 → ② 홈에서 내 레인 확인 → ③ 오늘 할 일 1개를 **＋ 새로 만들기**로 적기 → ④ My Agent에게 부수 업무 하나 맡겨보기. 끝.
