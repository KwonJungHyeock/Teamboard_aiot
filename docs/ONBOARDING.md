# Mission Deck 시작하기

플랫폼팀 업무 관리 도구입니다. 이 문서만 읽으면 오늘부터 씁니다.
Slack을 쓰던 분을 기준으로 썼습니다 — 익숙한 개념에 빗대 설명합니다.

최종 개정 2026-08-04 (MD-P-2026-015 §E)

---

## 0. Slack과 뭐가 다른가

| Slack에서는 | 여기서는 |
|---|---|
| 채널에서 대화하고, 결정은 스크롤을 거슬러 찾음 | **프로젝트** 하나를 열면 논의·업무·기록·결정이 탭으로 한자리 |
| 결정이 메시지에 묻힘 | **결정** 탭에 남고, 뒤집히면 취소선 + `→ 새 결정 #번호` |
| 나중에 볼 것은 북마크 | 메시지 hover → **저장**, 왼쪽 **저장됨**에 모임 |
| 멘션이 알림에 섞임 | **활동**에서 사람이 한 일 ⇄ 시스템 알림이 분리됨 |
| 진척은 사람이 적어서 공유 | 업무 진척 → 프로젝트 → **목표 달성률까지 자동 계산** |

첫 로그인 때 **3장짜리 안내**가 한 번 뜹니다. 나중에 다시 보려면
`⌘/`(Windows는 `Ctrl+/`) → 하단 **처음이신가요? 안내 다시 보기**.

---

## 1. 첫 설정 (3분)

1. 팀장에게 받은 **업무메일 + 임시 비밀번호**로 로그인합니다.
2. 첫 로그인이면 **비밀번호 변경**을 먼저 요구합니다(8자 이상).
3. 좌측 하단 **내 계정 → 프로필**에서 **표시 이름**을 확인하세요.
   이 이름이 타임라인 레인·담당자 표시에 쓰입니다. 로그아웃도 이 화면 상단에 있습니다.

---

## 2. 화면별로 하는 일

### 홈 `/`
하루를 여는 화면. 팀 타임라인(영역별 롤업 ⇄ 개별 업무 전환), 지연·마감 임박, 이번 달 목표,
승인 대기가 한 화면에 있습니다. **바 색 = 업무 영역**, 우측 코랄 캡 = 지연.

### 내 업무 `/tasks`
내가 할 일. 행을 클릭하면 우측 **상세 패널**이 열려 상태·담당·기한·진척·설명·코멘트를
그 자리에서 고칩니다(자동 저장, 화면 이동 없음).

### 캘린더 `/calendar`
일정(시간 있는 것)과 업무(기한만 있는 것)를 나눠 봅니다. 빈 칸의 **＋** 로 그 자리에서 업무 추가.

### 프로젝트 `/projects`
**여기가 중심입니다.** 프로젝트를 열면 탭 5개:

| 탭 | 하는 일 |
|---|---|
| 개요 | 진척·기간·담당·연결된 리소스 |
| 업무 | 이 프로젝트의 업무 목록 |
| 논의 | 스레드로 이야기. `@` 로 멘션, hover 로 리액션 |
| 캔버스 | 설계·자료조사 기록. 링크를 붙여넣으면 카드로 펼쳐짐 |
| 결정 | 확정된 것만. 뒤집히면 취소선과 함께 새 결정으로 이어짐 |

### 논의·결정 `/signals`
프로젝트를 가로질러 논의와 결정을 모아 봅니다. **결정 로그** 탭에서 "언제 무엇을 왜 정했는지"를
한 줄로 훑을 수 있습니다.

### 활동 `/activity`
알림함입니다. 왼쪽 레일에서 **멘션 · 배정 · 답글 · 승인 · 마감 · 결정** 으로 좁힐 수 있고,
**사람이 한 일**과 **시스템 알림**이 분리돼 있습니다.
`여기까지 읽음` 선 위쪽이 새 소식입니다. 여러 개를 골라 한 번에 읽음·보관 처리할 수 있고,
자주 쓰는 필터는 **저장된 뷰**로 고정해두면 한 번에 돌아옵니다.

### 저장됨 `/saved`
hover 액션바에서 **저장**한 것이 모입니다. Slack 북마크와 같은 자리입니다.

### 목표 `/goals`
연간 → 분기 → 월로 내려가는 목표판. **팀 목표**와 **내 목표**가 분리돼 있습니다
(개인 목표는 본인과 팀장만 봅니다).

> **핵심**: 목표에 **프로젝트를 연결**해두면 업무 진척이 프로젝트로, 프로젝트가 목표로 올라가
> 달성률이 자동 계산됩니다. 연결을 안 하면 영원히 `-` 입니다.

> **`-` 와 `0%` 는 다릅니다.** `-` 는 "연결된 업무가 없어 계산할 근거가 없음",
> `0%` 는 "업무가 있는데 아직 아무것도 진행되지 않음". 없는 숫자를 지어내지 않으려는 규칙입니다.

### 월간 보고 `/reports`
월별 성과를 화면 그대로 인쇄해 PDF로 저장합니다. 과거 달은 **그달의 스냅샷**을 씁니다 —
지금 시점 값으로 과거를 덧칠하지 않습니다. 스냅샷이 없는 달은 `기록 없음`으로 나옵니다.

### 허들룸 `/huddle` · 인수인계 `/handover`
함께 볼 안건을 올려 그 자리에서 정하는 곳(허들룸)과, 담당 업무를 넘길 때 쓰는 문서(인수인계).

### 에이전트 `/assistant`
자료조사·정리 같은 부수 업무를 AI에게 맡깁니다. **초안이 나오면 내가 승인해야** 팀 기록에 올라갑니다.
승인 대기는 좌측 **승인 대기**에 배지로 쌓입니다.

### 팀장 전용
**구성원 관리** · **설정** · **업무 현황** 은 팀장만 들어갑니다. 메뉴에도 보이지 않고,
주소를 직접 쳐도 막힙니다.

## 3. "이걸 어디에 적지?" — 3초 판단

- **할 일이 정해졌다** → **업무**. 담당·기한이 정해진 실행 단위입니다.
- **정해지지 않았고 의견이 필요하다** → 프로젝트의 **논의**, 함께 볼 것은 **허들룸**.
- **정해졌다** → **결정**으로 올립니다. 나중에 근거를 찾을 사람을 위해서입니다.

처음부터 완벽히 분류하지 않아도 됩니다. 논의 → 결정 → 업무로 자연스럽게 이어집니다.

## 4. 단축키

`⌘/` (Windows `Ctrl+/`) 를 누르면 전체 목록이 뜹니다. 이 표가 그 목록과 같은 내용입니다.

| 키 (mac / Windows) | 하는 일 |
|---|---|
| `⌘K` / `Ctrl+K` | **빠른 이동** — 프로젝트·업무·사람·결정 통합 검색 |
| `⌘/` / `Ctrl+/` | 단축키 목록 |
| `⌘F` / `Ctrl+F` | 화면 내 검색 (브라우저 기본 찾기는 `⌘⇧F`) |
| `⌘⇧A` / `Ctrl+Shift+A` | 활동으로 이동 |
| `⌘⇧S` / `Ctrl+Shift+S` | 저장됨으로 이동 |
| `⌘N` / `Ctrl+N` | 새 업무 |
| `⌘⇧\` / `Ctrl+Shift+\` | 리액션 피커 |
| `↑` | 입력창이 비었을 때 직전 내 코멘트 편집 |
| `Esc` | 패널·모달 닫기 (열린 게 없으면 목록을 읽음 처리) |

글자를 입력하는 중에는 `⌘K`·`⌘N` 만 살아 있습니다. 나머지는 오타를 막기 위해 잠깁니다.

**세 개만 외우세요**: `⌘K`(이동) · `⌘N`(새 업무) · `Esc`(닫기).

## 5. 처음 한 주에 이렇게

**1일차** — 프로필 이름 확인 → 홈 훑기 → `⌘K` 로 내 업무 찾아 열어보기
**2일차** — 내 업무의 상태·진척을 실제로 갱신. 진척은 스스로 적는 값입니다
**3일차** — 프로젝트의 **논의** 탭에 한 건 남겨보기. `@` 로 담당자 멘션
**4일차** — 논의에서 정해진 것을 **결정**으로 올려보기
**5일차** — **목표** 화면에서 내가 맡은 프로젝트가 목표에 연결돼 있는지 확인. 안 돼 있으면 연결

---

## 6. Notion은 "리소스"만

상태·일정·우선순위·진척은 Mission Deck에서 관리합니다. Notion에는 장문 문서·자료만 둡니다.
업무·프로젝트 상세의 **연결된 리소스**에 Notion URL을 붙여넣으면 카드로 연결됩니다.
설정은 [Notion 연동 설정](./NOTION_SETUP.md) 참고 (팀장용).

## 7. 자주 묻는 것

**Q. 달성률이 `-` 로만 나옵니다**
목표에 프로젝트가 연결되지 않았거나, 연결된 프로젝트에 업무가 없습니다. 목표 화면에서 연결하세요.

**Q. 진척률은 누가 적나요**
업무 담당자가 직접 적습니다. 여기서 프로젝트·목표로 자동 집계됩니다. 시스템이 추정하지 않습니다.

**Q. 알림이 너무 많습니다**
활동 화면에서 **사람 ⇄ 시스템**을 나눠 보거나, 항목 `⋯` → **이 프로젝트 알림 끄기**로 음소거하세요.

**Q. 결정을 잘못 올렸습니다**
지우지 말고 **새 결정으로 번복**하세요. 원래 결정에 취소선이 그어지고 `→ 새 결정 #번호`가 붙습니다.
왜 바뀌었는지가 남는 게 더 중요합니다.

**Q. 캔버스를 두 사람이 동시에 고치면요**
나중에 저장한 쪽이 안내를 받고 최신 내용을 다시 불러옵니다. 먼저 저장한 내용이 사라지지 않습니다.

**Q. 남의 개인 목표를 볼 수 있나요**
없습니다. 본인과 팀장만 봅니다. 주소를 직접 쳐도 막힙니다.

**Q. 화면이 이상합니다**
`오류 번호`가 보이면 그 번호와 함께 팀장에게 알려주세요. 로그에서 바로 찾을 수 있습니다.
