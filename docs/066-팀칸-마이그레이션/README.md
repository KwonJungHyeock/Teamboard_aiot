# 팀 칸 마이그레이션 — **승인 대기** (MD-P-2026-066 §F)

지시서 §F-54: 「마이그레이션 파일을 만들었으면 **푸시 전에 멈추고 보고한다.**
파일 내용을 그대로 보고에 적는다. 승인 뒤에 푸시한다.」

## 왜 이 폴더에 있는가

`lib/migrate.ts` 는 **`db/migrations/*.sql` 를 배포 뒤 첫 DB 접근에서 자동으로
적용한다.** 그 폴더에 파일을 두면

- 개발 기계에서도 다음 요청에 그냥 적용되고,
- `main` 에 올라가면 **프로덕션에 적용된다.**

승인 전에는 둘 다 일어나선 안 되므로, 파일을 **러너가 안 보는 자리**에 둔다.
여기 있는 `.sql` 은 아무도 안 돌린다.

## 승인되면 하는 일 — 두 줄

```
git mv docs/066-팀칸-마이그레이션/0036_team_column.sql      db/migrations/0036_team_column.sql
git mv docs/066-팀칸-마이그레이션/0036_team_column_down.sql db/migrations/rollback/0036_team_column_down.sql
```

그다음 푸시한다. 배포 뒤 첫 요청에서 러너가 적용한다.

## 무엇을 확인했나 (검사용 DB 에서)

프로덕션·개발 DB **어느 쪽에도 적용하지 않았다.** 대신 빈 DB 를 새로 만들어
`0001_baseline` 부터 `0035` 까지 러너와 **같은 순서로** 깔고, 그 위에서 돌렸다.

| 확인한 것 | 결과 |
|---|---|
| 0001~0035 를 깐 DB 에서 적용 | 오류 0 |
| 기존 줄이 있을 때 **채워지는가**(§F-50) | task · goal · project · note 각 1행 → 전부 `team_id=1` |
| **새 줄**도 채워지는가(§F-50) | `INSERT` 에 team_id 를 안 줬는데 `1` 로 들어갔다 (DEFAULT) |
| NOT NULL 이 걸리는가 | 네 표 다 `is_nullable = NO` |
| 두 번 돌려도 되는가 (멱등) | 두 번째 실행 오류 0 · 전부 skipping |
| 되돌리기 | 컬럼 4개 → 0개 · `team` 표 사라짐 |
| 되돌린 뒤 다시 적용 | 컬럼 다시 4개 |

검사용 DB 는 확인이 끝나고 지웠다.

## 도중에 나온 것 하나 — `db/schema.sql` 이 뒤처져 있다

처음엔 검사용 DB 를 `db/schema.sql` 로 깔고 돌렸는데
**`relation "note" does not exist`** 로 멈췄다. `note` 표는 `schema.sql` 에 없고
마이그레이션 `0026_personal_space.sql` 에만 있다.

러너 경로는 멀쩡하다 — 0026 이 0036 보다 먼저 돌기 때문이다. 다만
**`db:init`(schema.sql 만 적용)으로 만든 DB 는 `note` 가 없다.** 고치지 않았다
(§F 의 범위가 아니다). 백로그에 적었다.

## 판단한 자리 — 「기록」을 `note` 로 읽었다

지시서의 넷은 「업무 · 목표 · 프로젝트 · **기록**」이다. 앞의 셋은 표 이름이
그대로 있는데 「기록」은 이 제품에서 여러 가지를 뜻한다.

| 후보 | 지금 행 수 | 왜 골랐나 / 왜 뺐나 |
|---|---|---|
| `note` (메모) | 0 | **골랐다.** 사람이 만들고, 부모 줄이 없다 — 합칠 때 팀을 되찾을 길이 없다 |
| `task.description` | — | 표가 아니라 **칸**이다. v3 상세가 「기록」이라 부르는 그것 |
| `task_comment` | 6 | 업무에 매달려 있다. 부모가 team_id 를 들고 있으므로 따라온다 |
| `comment` | 12 | 위와 같다 |
| `activity_log` | 217 | **기계가 만든다.** 「사람이 만드는 줄」이 아니다 |
| `signal` | 8 | 목록에 없다. 다만 이것도 혼자 떠 있는 줄이다 — 지시가 있으면 한 줄 더한다 |

다르게 읽어야 하면 `.sql` 의 `ARRAY['task','goal','project','note']` 한 곳만
고치면 된다.
