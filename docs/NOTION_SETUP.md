# Notion 연동 설정 (MD-P-2026-012)

Mission Deck는 Notion을 **대체하지 않고 연동**합니다.

| 구분 | 어디에 두나 |
|---|---|
| 상태 · 일정 · 우선순위 · 진척 · 목표 | **Mission Deck** (시스템 오브 레코드) |
| 리소스 · 장문 문서 · 상세 기록 | **Notion** (서브) |

> Notion에 상태·일정을 두지 마세요. 진실의 원천이 둘로 갈리면 "3중 도구 왕복" 문제가 되돌아옵니다.
> 상태·날짜 양방향 동기화는 의도적으로 구현하지 않았습니다.

---

## 관리자 선행 작업 (한 번만)

연구소 Notion 계정으로 진행합니다.

### 1. Integration 생성
1. Notion → **설정 → 연결 → 연결 개발** (또는 https://www.notion.so/profile/integrations)
2. **새 API 통합** → 유형 **내부(Internal)**, 연결 대상 워크스페이스 = 연구소
3. 이름 예: `Mission Deck`
4. 발급된 **Internal Integration Secret**(`ntn_`로 시작)을 복사

### 2. 토큰 등록 (서버 전용)
Vercel → 프로젝트 → Settings → Environment Variables

```
NOTION_TOKEN = ntn_xxxxxxxxxxxxxxxxxxxx
```

- **클라이언트에 노출되지 않습니다.** 모든 Notion 호출은 서버 라우트를 거칩니다.
- `NEXT_PUBLIC_` 접두어를 절대 붙이지 마세요.

### 3. 페이지에 Integration 초대 ★ 빠뜨리기 쉬움
토큰만 등록하면 아무 페이지도 보이지 않습니다. **공유할 페이지마다 초대**해야 합니다.

1. 연동할 상위 페이지(예: `플랫폼팀 리소스`)를 엽니다
2. 우상단 **⋯ → 연결 → `Mission Deck`** 선택
3. 하위 페이지는 상속되므로 상위 한 번이면 충분합니다

### 4. Mission Deck에서 확인
1. **설정** 화면 → **Notion 연동** 카드
2. **[연결 테스트]** → "연결됨 · 워크스페이스 이름"이 뜨면 성공
3. **문서 생성 상위 페이지**에 3번의 페이지 URL을 붙여넣고 **저장**
   - 지정 전에는 `[Notion 문서 만들기]` 버튼이 비활성입니다

---

## 팀원 사용법

### 링크 붙여넣기
업무·프로젝트·결정 상세, 프로젝트 캔버스에서 **＋ 링크** → Notion URL 붙여넣기.
- 카드에 Notion 아이콘 + 페이지 제목 + 최종 수정일이 표시됩니다
- 메타 조회는 **15분 캐시**입니다 (Notion rate limit 보호)

### Notion 문서 만들기
업무·프로젝트 상세 → **[Notion 문서 만들기]**
- 상위 페이지 아래에 문서가 생기고, 본문 첫 줄에 **Mission Deck 백링크**가 들어갑니다
- 생성 즉시 해당 항목에 자동 연결됩니다

### 연결 해제
카드에 마우스를 올리고 **⋯ → 연결 해제**.
**Notion 원본은 삭제되지 않습니다.** 연결만 끊깁니다.

## 문제 해결

| 증상 | 원인·조치 |
|---|---|
| "접근 권한이 없습니다. Notion에서 이 페이지에 연동을 초대하세요." | 3번 초대 누락. 해당 페이지에서 ⋯ → 연결 → Integration 선택 |
| "페이지를 찾을 수 없습니다" | 삭제됐거나 초대되지 않음. Notion은 미초대 페이지도 404로 답합니다 |
| 카드에 URL만 보임 | 메타 조회 실패. 링크는 유지되며 다음 조회(15분 후)에 재시도합니다 |
| [Notion 문서 만들기]가 비활성 | 토큰 미등록 또는 상위 페이지 미지정. 설정 화면에서 확인 |

## 구현하지 않은 것 (의도적)
- Notion ↔ Mission Deck 상태·날짜 **양방향 동기화**
- Notion 데이터베이스를 업무 저장소로 사용
- Notion 전체 검색 통합
