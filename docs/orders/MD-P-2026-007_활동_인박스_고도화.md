# 작업지시서 — 활동(알림) 인박스 고도화 (MD-P-2026-007)
발행 2026-08-04 · 선행: MD-P-2026-006 완료

## 목적
활동을 **1급 표면**으로 승격하고, **사람 알림과 시스템 알림을 분리**해 알림 과부하를 사전 차단한다.
근거: Slack이 2026년 활동 탭을 전체 페이지로 재설계한 흐름 + 개발팀 최다 실패 모드 1위가
"봇·연동 알림이 사람 메시지를 익사시킴"(MD-R-2026-001 §3.1, §4.5)

## 범위
- `/activity` 페이지 전면 개편, 사이드바 배지 규칙, 알림 생성 규칙 정리.
- **새 알림 타입 추가 금지.** 기존 타입의 분류·표시·처리만 개선.

## A. 페이지 구조 (전체 페이지)
좌측 **필터 레일(200px)** + 중앙 **목록** + 우측 **SidePanel**(MD-P-2026-006 컴포넌트 재사용)

필터 레일 항목(각 행에 안읽음 수):
- 전체 / 멘션 / 배정 / 답글 / 승인 요청 / 마감 / 결정
- 하단 구분선 아래: **저장된 뷰** (§D)

## B. 사람 ⇄ 시스템 분리 ★핵심
목록 상단 세그먼트 `[사람] [시스템]`, **기본 = 사람**

| 구분 | 포함 |
|---|---|
| 사람 | 멘션, 업무 배정, 코멘트 답글, 승인 요청, 결정 확정 |
| 시스템 | 에이전트 작업 결과, 마감 자동 알림, 연동·배포 알림, 집계 갱신 |

- **사이드바 "활동" 배지 숫자 = 사람 안읽음만.** 시스템은 숫자 없이 작은 점(dot)으로만 표시.
- 시스템 탭은 기본 음소거(푸시·배지 없음). 사용자가 원하면 설정에서 해제.

## C. 일괄 처리
- 상단 우측: [모두 읽음] · [이 필터 모두 읽음]
- 항목 좌측 체크박스 → 다중 선택 → [읽음] [저장] [보관]
- Shift+클릭 범위 선택. 처리 후 토스트 + 실행취소.

## D. 저장된 뷰
- 현재 필터 조합(타입 + 사람/시스템 + 읽음상태)을 이름 붙여 저장 → 필터 레일 하단에 고정.
- 기본 제공 2개: **"내 멘션만"**, **"오늘 처리할 것"**(승인 요청 + 마감 D-2 이내 + 안읽음 멘션).
- 삭제·이름변경은 hover 액션바에서.

## E. 알림 생성 규칙 정리 (중복 방지)
- **마감 알림은 업무당 하루 1회.** D-2 / D-DAY / 지연(D+1 이후 최초 1회)만 발생. 매일 반복 발송 금지.
- 같은 스레드에 답글이 연속으로 달리면 **묶어서 1건**("답글 3개")으로 표시.
- 본인이 유발한 이벤트는 본인에게 알림 생성 금지.

## F. 음소거
- 항목 hover 액션바에 [⋯ → 이 프로젝트 알림 끄기].
- 상단에 임시 음소거 드롭다운: `1시간` / `내일 오전 9시까지` / `해제`. 활성 시 헤더에 상태 표시.

## G. 항목 표시
- 아이콘(타입별 색: 멘션=purple @ / 배정=teal ◱ / 답글=blue ↩ / 승인=coral ! / 마감=coral ⏱ / 결정=green ✓)
- 안읽음 = 제목 굵게 + 좌측 코랄 점. **"여기까지 읽음" 구분선** 유지(MD-P-2026-006 §F).
- 시간은 mono. 클릭 시 우측 패널에서 원본 열람(화면 이동 금지).
- 빈 상태: "새 활동이 없어요." + 저장된 뷰 안내.

## 제약
- 시각 토큰 변경 금지. 다크값은 사이드바·히어로에만.
- 읽음 처리는 낙관적 업데이트 + 실패 시 롤백.
- ⌘⇧A로 진입 가능해야 함. Esc로 패널 닫기.
- 대비 4.5:1, reduced-motion 대응.

## 보고 형식

6. **중복 알림 검증**: 마감 D-2 업무를 하루 두 번 조회해도 알림이 1건인지 확인 결과
