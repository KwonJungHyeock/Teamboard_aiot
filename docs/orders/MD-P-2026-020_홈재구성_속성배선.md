# D. 홈 재구성 (미착수분)

## D1. 페이지 헤더 (MD-P-019 §B 뼈대 사용)
- 브레드크럼: `워크스페이스 / 홈`
- 제목 `홈` (19px 800) · 부제 `2026.08.04 화 · 플랫폼팀` (12px --muted)
- 우측 액션: `가져오기`(고스트) · `＋ 새 업무`(코랄)
- 탭: `개요`(기본) / `내 초점` / `팀 현황`
- 필터바: 칩 `이번 분기`(활성) · `전체 기간` / 우측 끝 `NOW HH:MM KST` (mono, --muted)

## D2. 본문 배치 (개요 탭)
세로 순서 고정. 본문 패딩 16px 22px.

**(1) 다크 히어로 타임라인 — 전체 폭, 하단 여백 12px**
- 배경 `linear-gradient(150deg,#1A1F27,#0E1116)`, radius 9px, 패딩 13px 16px
- 우상단 코랄 글로우 `radial-gradient(circle, rgba(234,74,79,.22), transparent 68%)`
- 헤더 한 줄: `팀 타임라인`(12.5px 800) · `YYYY.MM`(14px 800 mono) · `[요약|상세]` 토글 · 우측 `● NOW`(11px, --coral-l)
- **높이 축소**: 바 트랙 17px, 바 간격 5px, 헤더~바 간격 10px (기존 대비 약 40% 축소)
- 바: 라벨 폭 76px 우측정렬(10.5px, rgba(255,255,255,.62)) / 트랙 배경 rgba(255,255,255,.05) radius 4px
- 바 내부 글자 9.5px 800, **대비 4.5:1 확보되는 색**(밝은 바 = 어두운 글자)
- NOW 세로선: 폭 1.5px, --coral-l

**(2) 2열 그리드 — `grid-template-columns: 1fr 300px; gap: 12px`**
- 좌열 위→아래: `목표` 블록 → (12px) → `결정 대기` 블록
- 우열 위→아래: `다가오는 일정` 블록 → (12px) → `나의 초점` 블록

## D3. 블록 공통 규격
- 배경 --surface, 1px --line, radius 9px, overflow hidden
- 블록 헤더: 패딩 9px 13px, 하단 1px --hair. 제목 12.5px 800. 우측 `전체 관리 →`(11px --muted)
- 안읽음/카운트 배지는 제목 우측에 코랄 pill(10px 800)
- 행: 패딩 8px 13px, 구분선 1px --hair, 마지막 행 구분선 없음, 폰트 12.5px

## D4. 블록별 내용
**목표** — `grid-template-columns: 1fr 74px 46px`
- 1열: `레벨 태그`(10px 700 mono --muted, 예 `연간` `Q3`) + 목표 제목(600, ellipsis)
- 2열: 상태칩 (온트랙=green / 리스크=coral / 대기=slate, 10px 800, radius 4px)
- 3열: 진척 `%` (11.5px 800 mono, 우측정렬). **데이터 없으면 `—`** (0% 금지)
- 정렬: 연간 먼저 → 분기. 같은 레벨은 리스크 > 온트랙 > 대기

**결정 대기** — `grid-template-columns: 1fr 74px 46px`
- 1열: LED 점(6px, 14일 초과=coral / 그 외=amber) + 논의 제목
- 2열: `답글 N` (10.5px --muted)
- 3열: age (11.5px 800 mono, **14일 초과 시 coral**)

**다가오는 일정** — `grid-template-columns: 52px 1fr 60px`
- 1열: 날짜 (11.5px 800 mono. 오늘은 `오늘`)
- 2열: 제목 (600, ellipsis)
- 3열: 종류(회의=blue / 리뷰=amber) 또는 `D-n`(mono, 임박 시 coral). 우측정렬
- **미래만** 노출(과거 마감 금지, 기존 규칙 유지)

**나의 초점**
- 아이콘 20px radius 5px (멘션=purple `@` / 승인=coral `!` / 업무=teal `◱` / 답글=blue `↩`)
- 본문 1줄 + 시각(10px mono --muted)
- **안읽음이면 굵게 + 좌측 코랄 점**(MD-P-018 §B 규격 재사용)

## D5. 나머지 탭
- `내 초점`: 나의 초점 항목 전체를 **목록 행(38px)** 으로. 활동 페이지 필터와 동일 규격
- `팀 현황`: 팀원별 행(담당자 / 진행 중 건수 / 지연 건수 / 평균 진척). 목록 행 규격 사용
- 두 탭 모두 신규 데이터 만들지 말고 기존 집계 재사용

# F1. 속성 블록 배선 (컴포넌트는 완성됨 → 실제 연결)
- 업무 상세 패널 상단의 **기존 셀렉트 폼을 제거**하고 `PropertyBlock` 으로 교체.
- 속성 순서 고정: `상태 / 담당 / 기간 / 우선순위 / 진행률 / 프로젝트 / 목표`
- 라벨 88px(11.5px --muted) + 값(12.5px 600). 행 hover 시 --surface-2
- **값 클릭 → 그 자리에서 편집**(드롭다운·날짜 피커·팝오버). 화면 이동·모달 금지
- 빈 값은 빈칸이 아니라 **행동 문구**: `＋ 목표 연결`, `＋ 담당 지정`, `기간 미정`
- 변경은 낙관적 업데이트 + 실패 시 롤백. 진척·목표 변경 시 집계 즉시 반영
- 속성 5개 초과분은 `속성 더보기`로 접기 가능(기본 펼침)

# F3. 연결된 리소스 자동 집계
- 문서 본문의 **link/embed 블록**과 속성의 **프로젝트·목표 연결**을 스캔해
  문서 하단 `연결된 리소스` 섹션에 **자동 표시**. 수동 등록 UI 만들지 말 것.
- provider별 아이콘(Notion·Figma·GitHub·내부). 클릭 시 새 탭(내부 링크는 우측 패널)
- 본문에서 링크를 지우면 섹션에서도 사라질 것(단일 소스)
- 항목 0개면 섹션 자체를 숨김(빈 섹션 금지)
