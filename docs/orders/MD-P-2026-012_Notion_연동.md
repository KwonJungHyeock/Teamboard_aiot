# 작업지시서 — Notion 연동 (MD-P-2026-012)
발행 2026-08-04 · 선행: MD-P-2026-011 완료

## 목적
팀 3축 중 **축1(리소스·기록)** 구현. Notion을 **대체하지 않고 연동**한다.
팀 확정 방침: "Notion은 리소스 저장·공유 및 업무기록 서브 용도. 연구소 계정으로 활성화·공유해 사용."

## 경계 (이번 작업의 핵심 원칙)
| 구분 | 위치 |
|---|---|
| 상태 · 일정 · 우선순위 · 진척 · 목표 | **Mission Deck (시스템 오브 레코드)** |
| 리소스 · 장문 문서 · 상세 기록 | **Notion (서브)** |

- **Notion에 상태·일정을 두지 말 것.** 진실의 원천이 둘로 갈리면 조사에서 확인한 "3중 도구 왕복" 문제가 재현된다.
- 이 경계를 UI 문구로도 노출한다(§F).

## A. 데이터 모델
`external_link` 신규 (Notion 전용 필드 만들지 말 것 — Figma·GitHub 확장 고려):
- `id`, `entity_type`('task'|'project'|'goal'|'decision'), `entity_id`
- `provider`('notion'|'figma'|'github'|'other'), `url`
- `title`, `icon_url`, `meta`(JSONB), `last_synced_at`
- `created_by`, `created_at`
- INDEX (entity_type, entity_id)

## B. Notion Integration 설정
- 서버 환경변수 `NOTION_TOKEN`(Internal Integration Secret). **클라이언트 노출 절대 금지.**
- 관리 화면에 연결 상태 카드: 연결됨/미연결 + [연결 테스트] 버튼 + 마지막 확인 시각.
- 미연결 시 안내: "연구소 Notion 계정에서 Integration을 생성하고, 공유할 페이지에 초대한 뒤 토큰을 등록하세요."
- **사용자 선행 작업(문서에 명시)**: Notion에서 Integration 생성 → 대상 페이지·데이터베이스에 해당 Integration 초대.

## C. 링크 붙여넣기 → 언퍼
- 업무·프로젝트·결정 상세, 그리고 **프로젝트 캔버스**에서 Notion URL 붙여넣기 → `external_link` 생성.
- 카드 표시: Notion 아이콘 + 페이지 제목 + 최종 수정일(mono). MD-P-2026-006 §E 언퍼 컴포넌트 재사용.
- **메타 조회 캐시**: `last_synced_at` 기준 15분 이내면 재조회 금지. Notion API rate limit(초당 3요청) 고려해 순차 처리.
- 실패 처리(깨진 카드 금지):
  - 권한 없음 → "접근 권한이 없습니다. Notion에서 이 페이지에 연동을 초대하세요." + 원본 링크 유지
  - 조회 실패 → 마지막으로 성공한 제목 표시, 없으면 원본 URL 텍스트

## D. Mission Deck → Notion 페이지 생성
- 업무·프로젝트 상세 `⋯ → Notion 문서 만들기`.
- 생성 위치: 설정에서 지정한 **상위 페이지(부모)** 아래. 미지정 시 버튼 비활성 + 설정 안내.
- 생성 내용: 제목 = 항목 제목, 본문 첫 줄에 **Mission Deck 백링크**(`#ID · 프로젝트명`).
- 생성 성공 시 자동으로 `external_link` 연결 + 토스트.

## E. 표시 위치
- 업무·프로젝트 상세 우측 패널에 **"연결된 리소스"** 섹션(Notion·Figma·GitHub 통합 표시).
- 프로젝트 개요 탭에 연결 리소스 수 표시.
- 링크 해제는 hover 액션바에서. **Notion 원본은 삭제하지 않음**(연결만 끊김) — 문구로 명시.

## F. 경계 안내 문구 (필수)
연결된 리소스 섹션 하단에 상시 노출:
> 상태·일정·우선순위는 Mission Deck에서 관리합니다. Notion은 리소스와 상세 기록용입니다.

## 제외 (하지 말 것)
- Notion ↔ Mission Deck **양방향 데이터 동기화** (상태·날짜 sync) — 진실의 원천 이중화 금지
- Notion 데이터베이스를 업무 저장소로 사용
- Notion 전체 검색 통합 (범위 초과)

## 제약
- 토큰은 서버에서만 사용. 모든 Notion 호출은 서버 라우트 경유.
- 외부 API 실패가 페이지 렌더를 막지 않을 것(언퍼는 비동기·점진 로딩).
- add-only 마이그레이션. 시각 토큰 변경 금지.
