# 작업지시서 — 디자인 개편 Phase 1: 핵심 3화면 (MD-P-2026-019)
발행 2026-08-04 · 시안: 03_디자인시안/05_개편_핵심3화면.html

## 목적
**작업자가 기록하기 쉽고 연동하기 쉬운 도구**로 만든다. 그 위에 규격화된 완성도를 얹는다.
Phase 1 = 홈 · 내 업무 · 업무 상세. 여기서 만든 규격을 Phase 2에서 나머지 화면에 퍼트린다.

# A. 디자인 토큰 전면 교체 (전역, 최우선)
웜 베이지 폐기 → 중성 톤. **기존 토큰 이름을 유지하고 값만 교체**해 화면 코드 수정을 최소화한다.

    --bg:#F7F8F9              (구 --paper #F6F4EF)
    --surface:#FFFFFF         --surface-2:#FBFCFC
    --ink:#16191D             --ink2:#525A66        --muted:#8A929C
    --line:#E5E8EB            --hair:#EFF1F3
    --sb1:#16191F             --sb2:#0D1014         (사이드바 다크 유지)
    --coral:#EA4A4F           --coral-d:#C7383C     --coral-bg:#FDEDED   (브랜드 유지)
    --blue:#3072E6            --blue-bg:#EAF1FE
    --teal:#0E9E92            --teal-bg:#E4F5F3
    --purple:#7C5CE0          --purple-bg:#F1EDFC
    --green:#128C58           --green-bg:#E3F4EC
    --amber:#D68910           --amber-bg:#FDF3E2
    --slate:#8A939F           --slate-bg:#EFF1F3
    --e1:0 1px 2px rgba(22,25,29,.05)
    --e2:0 4px 14px rgba(22,25,29,.08)
    --e3:0 12px 32px rgba(22,25,29,.14)
    --scrim:rgba(22,25,29,.45)    --scrim-strong:rgba(22,25,29,.78)

- 웜 계열 하드코드(#F6F4EF, #FBFAF6, #E8E2D7 등) **전수 검색해 제거**. grep 결과 0 확인.
- 영역색 배경(-bg)은 칩·태그 전용. 큰 면적에 쓰지 말 것.

# B. 페이지 뼈대 — 전 화면 공통 규격
위에서 아래로 **고정 순서**: 브레드크럼 → 제목+액션 → 탭 → 필터바 → 본문
- 헤더 영역 배경 --surface, 하단 1px --line. 본문 배경 --bg.
- 브레드크럼 11px --muted / 제목 19px 800 / 부제 12px --muted
- 액션 버튼은 **항상 우측 정렬**, 주 액션 1개만 코랄. 나머지는 고스트.
- 탭: 12.5px 700, 활성만 --ink + 하단 2px 코랄 밑줄
- 필터바: --surface-2 배경, 칩 높이 26px. 우측 끝에 건수·요약 텍스트
- 본문 패딩 16px 22px
- **이 뼈대를 컴포넌트 1개로 만들고 3화면이 공유할 것.** 화면마다 다시 짜지 말 것.

# C. 목록 = 행(row). 카드 금지
- **행 높이 38px 고정**, 폰트 12.5px, 좌우 패딩 13px, 구분선 1px --hair
- hover --surface-2 (120ms), 클릭 → 우측 패널
- 헤더 행: --surface-2 배경, 10.5px 800 --muted
- 컬럼 정렬: 텍스트 좌측 / **숫자·기한·진행률은 mono + tabular-nums**
- 진행률 = 폭 52px 바 + 우측 % 텍스트
- 상태 = LED 점(6px) + 라벨. 발광·애니 금지
- **기존 카드형 목록(승인 대기·논의·활동 등)도 이 규격으로 전환** (Phase 2 대상이지만 컴포넌트는 지금 만들 것)
- 카드는 **요약·대시보드 블록에만** 사용

# D. 홈
- 상단: 다크 히어로 타임라인(앵커 유지, **높이 축소**, 요약⇄상세 토글 유지). 바 내부 글자는 대비 확보한 색.
- 좌: 목표(연간·분기를 한 목록, 레벨 태그로 구분) → 결정 대기
- 우: 다가오는 일정 → 나의 초점
- 탭: 개요 / 내 초점 / 팀 현황
- 데이터 없는 목표는 — 유지(0% 금지) + [프로젝트 연결] 링크

# E. 내 업무
- 기본 필터 **완료 제외**, 기본 정렬 **기한 오름차순**(지연 → 임박 → 여유 → 기한없음)
- 컬럼: 업무 / 영역 / 프로젝트 / 우선순위 / 진행률 / 상태 / 기한
- 하단에 "완료 8건 숨김 · 완료 포함해서 보기" 링크
- 뷰 탭: 시트 / 보드 / 캘린더 / 타임라인 (같은 데이터, 같은 필터 상태 공유)

# F. 업무 상세 = 문서형 ★기록 편의의 핵심
**폼을 버리고 문서로 만든다.** 이 항목이 이번 개편에서 가장 중요하다.

## F1. 구조
1. **제목** 25px 800, 클릭 즉시 인라인 편집
2. "#ID · 최종 수정 · 자동 저장됨" (mono, 11.5px)
3. **속성 블록** — 라벨(88px) + 값의 한 줄 그리드. 상태·담당·기간·우선순위·진행률·프로젝트·목표
   - 각 행 hover 시 배경 강조, 클릭 시 그 자리에서 편집(팝오버/드롭다운). **화면 이동 없음**
   - 비어 있으면 "＋ 목표 연결" 처럼 **행동 문구**로 표시(빈칸 금지)
   - 속성 4개 초과분은 "속성 더보기"로 접기 허용
4. **본문** — 자유 기록 영역. 여기가 주인공

## F2. 기록 편의 (필수)
- **슬래시 명령(/)**: 제목 / 체크리스트 / 글머리 / 구분선 / 인용 / 코드 / 이미지 / 링크 임베드
- **붙여넣기 자동 인식**
  - URL 붙여넣기 → **임베드 카드**로 자동 변환 (원문 링크 유지)
  - 이미지 붙여넣기·드래그 → 업로드 (스토리지 미연결 시 기존 비활성 규격 유지)
  - 여러 줄 텍스트 → 문단 분리
- **체크리스트**: 체크 시 취소선 + --muted. 완료 개수를 진행률에 반영할지 여부는 토글로 선택
- @ 멘션 · : 이모지 자동완성 (기존 컴포넌트 재사용)
- **자동 저장**: 디바운스 800ms, 상단에 "저장 중… / 저장됨 HH:MM" 표시. 실패 시 재시도 + 사유
- 동시 편집은 캔버스와 동일한 baseUpdatedAt 낙관적 동시성 적용

## F3. 연동 편의 (필수)
- 본문 임베드 + 속성 연결을 모아 **"연결된 리소스" 섹션**에 자동 집계(수동 등록 불필요)
- Notion · Figma · GitHub · 내부 링크(업무/결정/프로젝트) 언퍼 지원
- 업무 ↔ 프로젝트 ↔ 목표 연결을 **속성에서 한 클릭**으로. 연결 시 진척 집계 즉시 반영
- 탭: 문서 / 논의 N / 활동 기록

# G. 완성도 규격 (측정 가능한 기준으로만 판정)
"완성도"를 감각이 아니라 규칙으로 강제한다. 아래를 벗어나면 결함으로 본다.
- **간격**: 4px 배수만 사용. 블록 간 12px, 섹션 간 16px, 본문 패딩 16/22px
- **폰트 스케일 6단**: 25 / 19 / 14 / 12.5 / 11.5 / 10.5 px. 그 외 크기 금지
- **라운드 3종**: 4px(칩·배지) / 7px(버튼·입력) / 9px(블록·카드). 그 외 금지
- **그림자 2단**: --e1(기본 표면) / --e2(떠 있는 요소: 팝오버·드롭다운). --e3은 모달만
- **선**: 1px만. --line(구획) / --hair(행 구분). 2px 이상 금지(탭 밑줄 예외)
- **인터랙션**: hover 120ms, 패널 슬라이드 180ms. prefers-reduced-motion 시 전부 즉시
- **포커스 링**: 모든 인터랙티브 요소에 2px 코랄 아웃라인(offset 2px)
- **로딩**: 스피너 대신 **스켈레톤**. 레이아웃 흔들림(CLS) 금지
- **빈 상태 3요소 필수**: 한 줄 설명 + 다음 행동 CTA + (선택)아이콘. 빈 박스 금지
- **정렬**: 숫자·기한·%는 우측 정렬 + mono. 텍스트는 좌측
- **코랄 사용 제한**: 주 CTA · 지연/리스크 · NOW · 활성 표시. 그 외 사용 시 사유 기재
- 대비 4.5:1 (계측 제출)

## 제약
- **기능 추가 금지.** 기존 기능의 표현·입력 방식만 개선.
- 3화면 외 레이아웃 변경 금지(토큰 교체로 인한 색 변화는 허용).
- 공통 컴포넌트(페이지 뼈대·목록 행·속성 블록)를 만들고 **재사용**할 것. 화면별 중복 구현 금지.
- 다크값은 사이드바·히어로에만.
