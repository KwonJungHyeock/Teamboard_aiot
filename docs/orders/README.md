## 소실 지시서 취급 규칙

**MD-P-2026-001 ~ 003 은 원문이 남아 있지 않다(초기 세션 소실).**

- **추정 복원을 하지 않는다.** 재구성한 문서는 실제 지시와 달라질 수 있고,
  이후 작업이 잘못된 기준 위에 쌓인다.
- 이 표에 "원문 없음"으로 기록만 남긴다.
- 원문이 발견되면 그때 원문 그대로 추가한다.
