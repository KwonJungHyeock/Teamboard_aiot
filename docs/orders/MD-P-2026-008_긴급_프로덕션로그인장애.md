# 작업지시서 — [긴급] 프로덕션 로그인 장애 (MD-P-2026-008)
발행 2026-08-04 · 우선순위 P0 · 다른 모든 작업 중단

## 상황
프로덕션(teamboard-aiot)에서 로그인 불가. 팀 전원 사용 중단 상태.
최근 배포: MD-P-2026-004~007 (결정 로그 / 프로젝트 워크스페이스 / 학습 전이 / 활동 인박스)

## 0. 서비스 복구 우선 (먼저 확인)
- Vercel Deployments에서 **마지막 정상 배포를 Production으로 Promote** 했는지 확인.
- 롤백 후 로그인 정상 여부 확인 → **정상이면 최근 배포가 원인**으로 확정.
- 롤백해도 안 되면 → 코드가 아니라 **환경변수·DB·외부 인증 제공자** 문제. §C로.

## A. 1순위 — 라우트·미들웨어 (MD-P-2026-006 §G 변경분)
- `/activity`, `/saved` 라우트 신설 + 기존 경로 리다이렉트를 넣었다.
- **인증 미들웨어의 matcher/공개경로 목록에 신규 경로가 반영됐는지 확인.**
- 확인 항목:
  - 로그인 페이지(`/login` 등)가 인증 필요 경로로 잘못 분류되어 **리다이렉트 루프**가 나는지
  - 리다이렉트 체인이 무한 반복하는지 (`/activity` → `/login` → `/activity` …)
  - 미들웨어가 세션 쿠키를 읽기 전에 리다이렉트를 걸어버리는지
- 재현: 시크릿 창에서 로그인 → Network 탭에서 3xx 연쇄 확인.

## B. 2순위 — DB 마이그레이션 (MD-P-2026-004~007 스키마 변경분)
프로덕션 DB에 아래가 **모두 적용됐는지 실제 조회로 확인**(코드만 보지 말 것):
- `decision` 테이블
- `project.goal_id`, `project.status`, `project.archived_at`, `project.owner_id`, `project.member_ids`
- `project_canvas` 테이블
- `goal.level`, `goal.period`
- 알림 관련 컬럼 변경
→ 누락 시 마이그레이션 적용. 적용 전 **DB 스냅샷/백업 필수**.
→ 세션·사용자 조회 경로가 위 테이블을 조인하는지 확인. 조인한다면 그게 로그인 실패 지점.

## C. 3순위 — 환경·인증 설정
- 인증 secret(예: `AUTH_SECRET`/`NEXTAUTH_SECRET`)이 Production 스코프에 존재하는지
- 세션 URL 변수가 실제 프로덕션 도메인과 일치하는지
- 쿠키 설정(secure·sameSite·domain)이 최근 변경됐는지
- 외부 인증 제공자 사용 시 콜백 URL 화이트리스트 확인

## D. 산출물 (필수)
1. **근본 원인 1문장** (추정 금지. 로그·응답코드 등 증거 명시)
2. 증거: 로그인 요청의 HTTP 상태코드 + 응답 본문 + 서버 로그 발췌
3. 수정 diff 요약
4. **회귀 테스트 추가**: 로그인 → 홈 진입 e2e 테스트 1건. 앞으로 배포마다 자동 실행.
5. 재발 방지: 라우트/미들웨어 변경 시 인증 경로 점검을 체크리스트로 고정

## 제약
- **프로덕션 DB에 파괴적 변경 금지.** 스키마 변경은 백업 후 add-only.
- 원인 확정 전 추가 기능 배포 금지.
- 롤백 상태를 유지한 채 수정하고, 검증 후 재배포.

## 보고 형식
1. 작업 요약 3줄 / 2. 근본 원인 + 증거 / 3. 수정 범위 / 4. 회귀 테스트 결과 / 5. 토큰
6. 캡처: 로그인 성공 플로우 (로그인 화면 → 홈)
