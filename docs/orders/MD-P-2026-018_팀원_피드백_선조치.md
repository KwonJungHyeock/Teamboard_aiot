# 작업지시서 — 팀원 피드백 선조치 (MD-P-2026-018)
발행 2026-08-04 · 출처: 팀원 QA 2건 + 스크린샷 리뷰 3건

## 범위 제한 (중요)
디자인 전면 개편이 예정되어 있다. **이번 라운드는 기능·데이터 결함만 수정한다.**
색상·여백·타이포 등 순수 시각 조정은 개편 때 일괄 처리하므로 **여기서 손대지 말 것.**
단, "정보가 안 보인다 / 잘못된 값이 보인다"는 기능 결함으로 간주해 수정한다.

## A. 활동 페이지 — 팀원 피드백 ①
**증상**: 활동에서 해당 항목의 마감을 수정하려고 하면 "간격만 좁아지고 내용이 보이지 않음"
- 우측 패널이 열리려다 내용 렌더에 실패하는 것으로 추정. **먼저 재현하고 원인을 특정할 것.**
- 확인 순서: 시스템 알림(마감) 클릭 → 패널 오픈 → 연결된 원본 업무 로딩 → 마감일 편집 가능 여부
- 요구 동작: 알림 클릭 시 **우측 패널에 원본 업무가 열리고, 그 자리에서 기한을 수정**할 수 있어야 한다.
  (화면 이동 없음. MD-P-006 SidePanel 규격)
- 로딩 중에는 스켈레톤, 실패 시 사유 + [다시 시도]. **빈 패널 금지.**

## B. 활동 페이지 — 팀원 피드백 ②
**증상**: 체크 후 읽음 처리해도 화면이 달라지지 않음
- 원인 추정: 활동 목록에 **안읽음 시각 표시가 적용되지 않음**(MD-P-006 §F 미반영).
  기능은 도는데 전후 차이가 보이지 않아 "안 된다"고 느끼는 상태.
- 수정:
  1. 안읽음 = **제목 굵게 + 좌측 코랄 점**, 읽음 = 일반 굵기·점 제거 (활동 목록에 반드시 적용)
  2. 읽음 처리 후 **필터 레일 카운트가 즉시 감소**할 것
  3. 처리 결과 **토스트 + 실행취소** 노출
  4. **"여기까지 읽음" 구분선**도 활동 목록에 적용
- 검증: 안읽음 3건 → 1건 체크 → 읽음 → 목록 표시·카운트·토스트가 모두 변하는지 캡처로 제출

## C. 시스템 알림에 사람용 액션바가 붙는 문제 (신규 발견)
- 현재 마감 알림 hover 시 `리액션 · 답글 · 저장 · ⋯` 이 노출된다. 시스템 알림에 이모지·답글은 무의미하다.
- 수정: **액션바를 구분**한다.
  - 사람 알림(멘션·배정·답글·승인): 기존 4종 유지
  - 시스템 알림(마감·에이전트·연동): `저장` · `원본 열기` · `⋯(음소거)` 만
- MD-P-007 §B의 사람/시스템 분류를 액션바까지 일관되게 적용할 것.

## D. 내 업무 — 정렬 기준 개선 (팀원 피드백)
**기본 정렬을 아래로 변경**:
1. **완료 제외**(기본 필터). 상단에 `완료 포함` 토글 제공, 선택은 사용자별로 기억.
2. 정렬: **기한 오름차순** (지연 → 임박 → 여유 → 기한없음 순). 기한 없는 항목은 **맨 뒤**.
3. 같은 기한이면 우선순위(높음→보통→낮음), 그다음 최신 작성순.
- 정렬 드롭다운 제공: `기한순(기본)` / `우선순위순` / `최신 작성순` / `진척순`. **선택 상태 기억.**
- 필터·정렬 상태를 URL 쿼리에 반영(공유 가능).

## E. 완료 업무의 D-day 표기 (신규 발견)
- 완료된 업무에 `D+26` 처럼 경과일이 계속 표시된다. 지연으로 오독된다.
- 수정: **상태가 완료면 `완료 2026-07-09` 형식으로 완료일 표시.** D+ 표기는 미완료 항목에만.
- 완료일이 없으면 `완료`만 표시(추정 금지).

## F. 업무-목표 연결 비어있음 (확인 요청)
- `내 업무` 목표 컬럼이 대부분 `—` 다. MD-P-009로 연결 UI는 만들었으나 실데이터가 비어 있는 상태로 보인다.
- **코드 결함인지 데이터 미입력인지 판별해 보고할 것.** 코드 문제면 수정, 데이터 문제면 미연결 업무 목록 제출.
