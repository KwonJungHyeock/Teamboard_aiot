# 작업지시서 — 전수 점검 + 디자인 마감 (MD-P-2026-013)
발행 2026-08-04 · 선행: MD-P-2026-004~012 전부 반영

## 목적
3축 기능이 빠르게 들어가는 동안 **화면 검토 없이 8건이 연속 배포**됐다.
모든 화면을 한 번씩 돌며 **기능 결함과 시각 불일치를 동시에** 잡는다. 두 번 돌지 않기 위해 한 패스로 처리한다.

## 방식
화면 단위로 진행. 각 화면마다 아래 4가지를 점검하고 **표로 결과 제출**(정상/수정/보류 + 수정 내용).
1. **기능** — 버튼·링크가 실제로 동작하는가. 저장·삭제·연결이 반영되는가
2. **상태** — 빈 상태 / 로딩 / 실패 / 권한없음 화면이 있는가 (`-`와 0% 구분 포함)
3. **시각** — 카드 통일, 여백 8px 그리드, 그림자 단계, mono 데이터, 코랄 남용 없음, 다크값은 사이드바·히어로에만
4. **전이** — 우측 패널 규칙, hover 액션바, 단축키, 용어(활동·저장됨) 일관성

## 점검 대상 화면 (전부)
홈 / 내 업무 / 캘린더(월·주) / 타임라인(요약·상세) / 보드 / 프로젝트 상세(개요·업무·논의·캔버스·결정) /
논의·결정 / 승인 대기 / 활동(사람·시스템) / 저장됨 / 목표(팀·내) / 목표 상세 / 월간 보고(성과·승인) /
허들룸 / 인수인계 / 관리 / 로그인 / 에이전트

## 필수 확인 항목 (그동안 미검증분)
- **MD-P-006 §H 전이 검증 6항목** — 아직 결과 미제출. 실제 테스트 후 O/X + 실패 원인
- MD-P-006 §E **링크 언퍼**, §F **"여기까지 읽음" 구분선** 실제 동작
- MD-P-005 **캔버스 동시 편집** — 두 창에서 같은 캔버스 편집 시 서로 덮어쓰지 않는가
- MD-P-009 **수동 진척값**이 자동 집계에 덮이지 않는가
- MD-P-004 **결정 번복** — 취소선 + "→ 새 결정 #ID" 링크 실제 연결
- MD-P-007 **마감 알림 중복** — 같은 업무가 하루 2건 이상 생성되지 않는가

## 디자인 마감 기준 (시각 항목 판정 기준)
- 카드: 흰 배경 · 라운드 · `--e1` 그림자 · hover 시 `translateY(-2px)`+`--e2`
- 간격: 카드 padding 17~18px, 카드 간 gap 16px, 섹션 여백 22~26px
- 데이터(ID·%·D-day·시각·금액): **mono + tabular-nums** 예외 없이
- 구분선: `--hair` 1px. 굵은 선 금지
- 코랄: CTA·리스크/지연·NOW·경보에만. 그 외 사용 시 사유 기재
- 영역색·상태색은 확정 팔레트 준수. 임의 색 추가 금지
- 빈 상태: 반드시 안내 문구 + 다음 행동 CTA. 빈 박스 금지
- **다크 grep 0** — 워크스페이스 표면에 다크 하드코딩이 없는지 실제 검색해 확인

## 제약
- **리팩터링 금지.** 발견한 결함 수정만. 구조 변경이 필요하면 보류로 남기고 사유 기재
- 새 기능 추가 금지
- 대비 4.5:1, reduced-motion 전 화면 확인

## 보고 형식
1. 작업 요약 3줄
2. **점검 결과 표** — 화면 × (기능/상태/시각/전이) 정상·수정·보류
3. **필수 확인 항목 결과** (위 6건, 증거 포함)
4. 보류 목록 + 사유 (다음 작업 후보)
5. 토큰
6. 캡처: 수정 전후가 드러나는 화면 위주로 최소 8장
