# 작업지시서 — 문서 경로 정리 (MD-P-2026-021)
발행 2026-08-04 · 우선 처리(다음 기능 작업 전)

## 목적
산출물이 리포지토리와 외부 폴더에 흩어져 CC가 참조하지 못하는 문제가 발생했다(MD-P-019 시안 누락).
**리포지토리를 단일 원천으로 확정**하고, 폴더 규칙을 문서로 못박는다.

## 0. 선행 확인 (먼저 보고)
- docs/RUNBOOK.md 와 docs/OPEN-MD-P-2026-015.md 가 main에 없다.
  MD-P-015 보고에는 "RUNBOOK.md 신규"가 포함돼 있었다.
  → **015 작업물이 main에 병합되었는지 확인하고 결과를 먼저 보고할 것.** 미병합이면 병합 여부를 묻고 대기.

## 1. docs/ 재편
목표 구조:

    docs/
    ├ README.md          ← 신규. 폴더 규칙·문서번호 체계 (§2)
    ├ SPEC.md            제품 명세
    ├ RUNBOOK.md         운영·배포·롤백·장애 대응
    ├ ONBOARDING.md      팀원용 사용 안내
    ├ CHANGE-GUIDE.md    변경 가이드
    ├ NOTION_SETUP.md    Notion 연동 설정
    ├ orders/            ← 신규. 작업지시서 MD-P-YYYY-NNN_*.md
    ├ reports/           ← 신규. 완료·감사 보고서 (AUDIT-*, OPEN-* 여기로 이동)
    ├ design/            ← 신규. 시안 HTML
    ├ audit/             계측 원본 JSON (유지)
    ├ shots/             캡처 (유지)
    └ archive/           구버전·폐기 문서 (유지)

작업:
- AUDIT-MD-P-2026-013.md, AUDIT-MD-P-2026-016.md, OPEN-MD-P-2026-015.md(있으면) → docs/reports/ 로 이동
- docs/prototype/ 내용을 확인해 **시안이면 docs/design/ 으로 이동**, 폐기된 것이면 docs/archive/ 로 이동.
  판단이 애매하면 이동하지 말고 목록만 제출.
- 이동은 git mv 로 이력 보존. **삭제 금지.**
- 이동 후 문서 내부의 상대 경로 링크가 깨지지 않는지 확인·수정.

## 2. docs/README.md 작성 (신규)
아래 내용을 담을 것.

**단일 원천 원칙**
- 이 리포지토리가 프로젝트 산출물의 단일 원천이다.
- CC는 **리포지토리 안에만** 쓴다. 외부 폴더 경로를 참조하거나 기록하지 않는다.
- 지시서가 리포 밖 경로를 가리키면 **그 사실을 먼저 보고**하고 진행 여부를 묻는다.

**폴더별 용도** — §1 구조표를 그대로 기재

**문서번호 체계**
- MD-{R|P|V|M}-{연도}-{일련번호}
- R=조사·검토 / P=기획·지시 / V=회고·QA / M=월간성과
- 지시서 파일명: docs/orders/MD-P-2026-020_홈재구성_속성배선.md
- 보고서 파일명: docs/reports/MD-P-2026-020_완료보고.md

**작업 흐름**
1. 지시서가 docs/orders/ 에 추가된다
2. CC가 구현하고 docs/reports/ 에 완료 보고서를 남긴다
3. 캡처는 docs/shots/{문서번호}-*, 계측 원본은 docs/audit/ 에 둔다
4. 시안은 docs/design/ 에서만 참조한다

## 3. 기존 보고서 정리
- docs/reports/ 로 옮긴 보고서 파일명을 문서번호 규칙에 맞게 통일(MD-P-2026-013_감사보고.md 형식).
- docs/shots/ 하위 캡처가 문서번호 접두사를 갖도록 정리(예 13-* → MD-P-2026-013-*).
  파일 수가 많으면 **폴더로 묶는 방식**(shots/MD-P-2026-013/)을 택해도 좋다. 택한 방식을 보고할 것.

## 제약
- **파일 삭제 절대 금지.** 이동·이름변경만.
- 코드 변경 없음. 문서·경로 정리만.
- 이동으로 깨지는 링크·이미지 참조가 없는지 확인 후 보고.
