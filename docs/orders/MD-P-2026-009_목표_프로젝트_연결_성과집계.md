# 작업지시서 — 목표↔프로젝트 연결 및 성과 집계 (MD-P-2026-009)
발행 2026-08-04 · 선행: MD-P-2026-005·006·007 병합 완료

## 목적
홈의 목표 진척이 전부 `-`(0%)인 상태를 해소한다. 원인은 코드가 아니라 **목표에 프로젝트가 연결되지 않아
집계 대상이 없기 때문**이다. 연결 UI를 만들고 트리 집계를 실제로 돌게 한다.
동시에 팀 3축 중 **축3(성과관리)** 요구사항 중 누락된 **월 목표**와 **팀/개인 구분**을 채운다.

## 범위
- 목표 페이지, 목표 상세, 프로젝트 헤더 연결부, 홈 목표 카드, `goal` 스키마.
- 다른 페이지 레이아웃 변경 금지.

## A. 스키마 확장
`goal`:
- `level`: 'annual' | 'quarter' | **'month'** (월 추가)
- `period`: 연간 `2026` / 분기 `2026-Q3` / 월 `2026-08`
- **`scope`: 'team' | 'personal'** (신규)
- **`owner_id`**: personal일 때 필수, team이면 nullable
- `parent_goal_id` (nullable) — 월→분기→연간 상위 연결
- `progress_manual` (nullable) — 수동 입력값
- `progress_auto` — 집계 결과(읽기 전용)

기존 목표 마이그레이션: scope='team', level은 현재 값 유지. 파괴적 변경 금지(add-only).

## B. 목표 ↔ 프로젝트 연결 UI ★핵심
### B1. 목표 상세에서
- "연결된 프로젝트" 섹션 + [＋ 프로젝트 연결] → **팝오버**(화면 이동 금지)에서 다중 선택.
- 이미 다른 목표에 연결된 프로젝트도 선택 가능하되, 목록에 "○○ 목표에 연결됨" 표시.
- 연결 해제는 항목 hover 액션바에서. 해제 시 진척 즉시 재계산.

### B2. 프로젝트 헤더에서 (MD-P-2026-005 §B1 보완)
- [목표 연결] CTA가 실제로 동작하는지 확인·수정. 단일 선택.
- 연결 후 헤더에 "→ 2026 Q3 · ○○" 표시, 클릭 시 목표 상세로 이동.

### B3. 일괄 연결 (초기 데이터 채우기용)
- 목표 페이지 상단에 [연결 안 된 프로젝트 N개] 배너 → 클릭 시 미연결 프로젝트 목록에서 목표를 골라 한 번에 연결.

## C. 진척 집계 규칙 (명문화 — 이대로 구현)
1. **업무 진척** = 사용자 입력값(0~100).
2. **프로젝트 진척** = 소속 업무 진척의 **기간 길이 가중 평균**. 업무 0건이면 `null`(0% 아님).
3. **목표 진척**
   - `progress_manual`이 있으면 **그 값 우선** + UI에 "수동" 배지.
   - 없으면 = 연결된 프로젝트 진척의 평균(진척 `null`인 프로젝트는 분모에서 제외).
   - 연결 프로젝트가 0개거나 전부 `null`이면 **`-` 표시 + "프로젝트를 연결하세요" CTA**. 0%로 표시하지 말 것.
4. **상위 목표 롤업**: 월 → 분기 → 연간. 하위 목표가 있으면 하위 평균, 없으면 자기 프로젝트 집계.
5. 재계산 시점: 업무 진척 변경 / 업무-프로젝트 연결 변경 / 프로젝트-목표 연결 변경. **순환 참조 방지**(parent 체인 깊이 3 제한).

## D. 목표 상태 자동 판정
- 온트랙 / 리스크 / 대기 를 수동 선택 대신 **기본 자동 판정**(수동 지정 시 수동 우선):
  - 기간 경과율 대비 진척률이 −15%p 이상 뒤처지면 **리스크**
  - 진척 0%이고 시작일 경과했으면 **리스크**
  - 시작 전이면 **대기**, 그 외 **온트랙**, 100%면 **완료**

## E. 팀 / 개인 목표
- 목표 페이지에 세그먼트 `[팀 목표] [내 목표]`.
- 개인 목표는 본인과 팀장만 조회. 생성 시 scope 선택.
- 개인 목표도 프로젝트·업무 연결 가능(같은 집계 규칙 적용).
- 홈 목표 카드: **팀 목표 우선 표시**, 하단에 "내 목표 N건" 한 줄 링크.

## F. 홈 목표 카드 보완
- 현재 연간 1 + 분기 N 구조 유지. **월 목표는 홈에 표시하지 않음**(목표 페이지에서만).
- 진척 없는 목표는 `-` + 흐린 바 + [프로젝트 연결] 링크. 지금처럼 빈 `-`만 두지 말 것.

## 제약
- **0%와 `-`(데이터 없음)를 반드시 구분**할 것. 정직 원칙(추정치·placeholder 금지).
- 집계는 서버에서 계산. 클라이언트 계산 금지.
- 대비 4.5:1, reduced-motion 대응. 시각 토큰 변경 금지.
