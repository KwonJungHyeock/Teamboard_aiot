# 작업지시서 — 프로젝트 워크스페이스 통합 (MD-P-2026-005)
발행 2026-08-04 · 선행: MD-P-2026-004(결정 로그) 완료

## 목적
프로젝트 하나를 열면 **논의·업무·캔버스·결정**이 한 곳에서 끝나게 한다. Slack의 "채널"에 해당하는
우리의 작업 단위를 완성하는 작업이며, 동시에 프로젝트가 목표 트리에 매달려 **달성률이 자동 집계**되게 한다.
근거: MD-R-2026-001 §5, §7.1

## 범위
- 프로젝트 상세 페이지(신규 통합), 사이드바 프로젝트 트리, `project` 스키마 확장.
- 홈·캘린더·타임라인 레이아웃 변경 금지(링크 연결만).

## A. 데이터 모델
`project` 확장:
- goal_id (FK→goal, nullable) — **이 프로젝트가 기여하는 월/분기 목표**
- status ('진행'|'보류'|'완료'|'보관')
- archived_at (nullable)
- owner_id, member_ids[]

`project_canvas` 신규: id, project_id, blocks(JSONB), updated_at, updated_by
- block 타입: `text` | `checklist` | `link`(언퍼 메타 포함) | `image`(**Blob 연결 후 활성**)

## B. 화면 구조
프로젝트 상세 = **헤더 + 탭 + 우측 슬라이드인 패널**

### B1. 헤더 (고정)
- 프로젝트명(인라인 편집) · 영역 칩 · 상태 칩
- **연결 목표 표시**: "→ 2026 Q3 · 웹 플랫폼 MVP 출시" 클릭 시 목표로 이동. 미연결 시 [목표 연결] CTA
- 멤버 아바타 스택(최대 5 + "+N")
- 우측: [＋ 업무] · [⋯ 더보기(보관·설정)]

### B2. 탭 (좌→우 순서 고정)
| 탭 | 내용 |
|---|---|
| 개요 | 진척 롤업(업무 기반 자동 계산), 다가오는 마감 3건, 최근 활동 5건, 미해결 논의 수 |
| 업무 | **테이블 ⇄ 보드 전환**. 커스텀 필드(상태·담당·기간·우선순위·진척). 항목 클릭 → 우측 패널 상세 |
| 논의 | 기존 논의 스레드 목록. 미해결 상단, age 14일 초과 coral |
| 캔버스 | §C |
| 결정 로그 | MD-P-2026-004 결과물 연결. 최신순, 번복 표시 유지 |

### B3. 우측 슬라이드인 패널 ★학습 전이 규칙
- **업무 상세·논의 스레드·멤버 프로필이 모두 같은 자리(우측 패널)에서 열린다.** 새 화면으로 이동시키지 말 것.
- 폭 420px, Esc로 닫기, 열린 상태에서 좌측 목록 계속 조작 가능.
- 근거: Slack의 thread pane 패턴. 이직 시 학습 전이의 핵심 요소(MD-R-2026-001 §6.2)

## C. 프로젝트 캔버스 (신규)
- 프로젝트별 1개. **과정 기록의 본체** — 자료조사·설계 메모·참고 링크가 쌓이는 곳.
- 블록 편집: 인라인 편집 + 자동저장(디바운스 800ms) + "○○님이 방금 수정" 표시.
- 지원 블록: 텍스트(마크다운 서식), 체크리스트, **링크 임베드(언퍼 카드)**.
  - 링크 언퍼 우선 대상: **Figma**, Notion, GitHub. 제목·썸네일·도메인 표시.
- **이미지 블록은 UI만 만들고 비활성**(툴팁: "스토리지 연결 후 사용 가능"). Blob 연결 시 플래그로 활성화.
- 빈 상태: "이 프로젝트의 설계·자료조사를 여기에 기록하세요. Figma 링크를 붙여넣으면 카드로 표시됩니다."

## D. 사이드바 트리
- "업무 영역" 하위에 **프로젝트를 트리로** 노출: 영역 → 프로젝트. 기본 접힘(아코디언 규칙 유지).
- 프로젝트 행: 영역색 dot + 이름 + 미해결 논의 수(있을 때만).
- 보관된 프로젝트는 트리에서 숨기고 "보관됨 보기" 토글로만 노출.

## E. 목표 연동 (트리 집계)
- 프로젝트 진척 = 소속 업무 진척의 가중 평균(업무 기간 길이 가중).
- **목표 진척 = 연결된 프로젝트 진척의 평균**으로 자동 갱신. 수동 입력값이 있으면 수동값 우선하되 "수동" 배지 표시.
- 목표 상세에 "연결된 프로젝트" 목록 표시(역방향 링크).

## F. 보관 (아카이브)
- [⋯ → 보관]: 확인 팝오버 후 status='보관', archived_at 기록.
- **삭제 아님.** 검색·결정 로그에서 계속 조회 가능. 보관 프로젝트는 읽기 전용 + 상단 배너("보관된 프로젝트입니다").
- 근거: Slack 아카이브 정책(MD-R-2026-001 §4.1)

## 제약
- 기존 Mission Deck OS 토큰 사용. 다크값은 사이드바·히어로에만.
- 탭 전환은 **리로드 없이** 클라이언트 상태로. URL 쿼리에 탭 반영(공유 가능).
- 자동저장 실패 시 롤백 + 토스트. 낙관적 업데이트 필수.
- 대비 4.5:1, reduced-motion 대응. 날짜는 공용 taskDays() 단일 소스.
