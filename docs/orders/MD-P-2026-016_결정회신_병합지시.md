## ① Blob 토큰 — B안 (목 구현 + 운영 실검증)
- 개발 환경에 운영 비밀값을 내려보내지 않는다. 지금 구조를 유지한다.
- `@vercel/blob` **실제 SDK 호출 경로로 구현**할 것. 자체 추상화 레이어를 새로 만들지 말 것.
- 목(mock)은 **테스트에서만** 사용하고 런타임 코드에 남기지 않는다.
- 지시서 검증항목 (a)(b)는 목으로 선검증하되, **운영 배포 후 아래 2건을 실검증하고 별도 보고**:
  1. 이미지 블록 삭제 시 Blob 객체가 실제로 사라지는가
  2. 업로드 → 새로고침 → 이미지가 그대로 보이는가(URL 영속성)
- 토큰 미존재 시 현재의 비활성 동작(툴팁 · 503 안내)을 그대로 유지한다.

## ③ 히어로 타임라인 바 — 명도 하향 철회. 텍스트 색을 바꿀 것 ★
- **현재 방식(색상 65% 명도 하향)을 되돌린다.** 대비 문제의 원인은 색이 밝아서가 아니라
  **밝은 바 위에 흰 텍스트**를 얹었기 때문이다.
- 수정 방식:
  - 바 배경색 = **원래 영역색으로 복원**(선명도 유지)
  - 바 내부 텍스트·아이콘 = **차콜(`--ink` 계열)** 로 변경 → 대비 확보
  - 단, 원래부터 어두운 바(지연=coral 등 배경 대비 4.5:1 이상 확보되는 경우)는 **흰 텍스트 유지**
- 판정: 각 바마다 실제 대비를 계측해 4.5:1 이상인 쪽(흰 or 차콜)을 선택. **계측표 제출.**
- 결과적으로 영역색 정체성이 유지되면서 대비도 통과해야 한다.
