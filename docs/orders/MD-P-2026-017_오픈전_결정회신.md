## ① 테스트 데이터 삭제 — 조건부 승인. 아래 절차를 반드시 지킬 것
**삭제는 이번 오픈 준비에서 유일하게 되돌릴 수 없는 작업이다.**

1. **백업 선행(필수)** — RUNBOOK §5 절차로 Neon 스냅샷 또는 수동 덤프를 먼저 확보하고,
   덤프 파일 경로·크기·시각을 보고에 기재한다. 백업 없이 삭제 금지.
2. **삭제 직전 목록 재출력** — 실행 직전에 대상을 한 번 더 출력해 로그로 남긴다.
   (그 사이 실데이터가 섞였을 수 있음)
3. **삭제 순서 고정** — 연결 해제 → 하위 → 상위
   `프로젝트-목표 연결 해제` → `업무·논의·결정·캔버스` → `프로젝트` → `목표`
   역순으로 지우면 고아 레코드와 집계 오류가 남는다.
4. **삭제 후 검증** — 홈 목표 진척 / 타임라인 / 활동 인박스에 깨진 참조나 빈 카드가 없는지 확인.
   진척값이 삭제 전후로 어떻게 바뀌었는지 전후 값 제시.
5. **실데이터로 판단이 애매한 항목은 삭제하지 말고 별도 목록으로 남길 것.** 확신 없는 건 남긴다.
