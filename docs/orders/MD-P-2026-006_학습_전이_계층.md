# 작업지시서 — 학습 전이 계층 (MD-P-2026-006)
발행 2026-08-04 · 선행: MD-P-2026-005 완료

## 목적
Slack 사용 경험이 Mission Deck에서 그대로 통하고, 반대로 팀원이 이직해 Slack을 써도 즉시 적응하게 만든다.
원칙: **학습 전이는 색이 아니라 배치와 동작에서 발생한다.** 시각 아이덴티티는 우리 것을 유지하고,
단축키·패널 규칙·상호작용 관용구·용어를 Slack과 일치시킨다. 근거: MD-R-2026-001 §6

## 범위
- 전역 단축키 시스템, 전역 SidePanel 컴포넌트, hover 액션바, 자동완성, 링크 언퍼, 읽음 표시, 용어 라벨.
- 신규 화면 생성 없음. 기존 화면의 상호작용만 통일.

## A. 전역 단축키
| 키 (macOS / Windows) | 동작 |
|---|---|
| ⌘K / Ctrl+K | 빠른 이동 — 프로젝트·업무·사람·결정 통합 퍼지 검색. 최근 방문 우선 노출 |
| ⌘/ / Ctrl+/ | 단축키 목록 모달 |
| ⌘F / Ctrl+F | 현재 화면 내 검색 (앱이 가로챔. 모달 상단에 "브라우저 검색은 ⌘⇧F" 안내) |
| ⌘⇧A / Ctrl+Shift+A | 활동(알림) 열기 |
| ⌘⇧S / Ctrl+Shift+S | 저장됨 열기 |
| Esc | 우측 패널·모달 닫기 → 없으면 현재 목록 읽음 처리 |
| ↑ (입력창 비었을 때) | 직전 내 코멘트 편집 |
| ⌘⇧\ / Ctrl+Shift+\ | 리액션 피커 |
| ⌘N / Ctrl+N | 새 업무(빠른 생성 팝오버) |

- OS 감지해 표기 자동 전환(⌘ ↔ Ctrl).
- **모든 단축키는 ⌘/ 목록에 반드시 노출**. 숨은 단축키 금지.
- 입력 중(textarea/input 포커스)에는 ⌘K·⌘N 외 전역 단축키 비활성.

## B. 전역 우측 패널 (SidePanel) — 최우선
- **업무 상세 · 논의 스레드 · 멤버 프로필 · 결정 상세**를 전부 하나의 컴포넌트로 통일. 폭 420px, 우측 슬라이드인.
- 규칙: Esc로 닫기 / 열린 상태에서 좌측 목록 계속 조작 가능 / **스택 깊이 1**(패널 안에서 다른 항목 열면 교체, 중첩 금지) / URL에 패널 상태 반영(공유 가능).
- **작업 전 전수 조사 필수**: 현재 "새 화면으로 이동"하는 지점을 모두 찾아 패널 전환 목록을 보고서에 제출한 뒤 변경할 것.
- 근거: Slack thread pane. 같은 자리에서 열리는 것이 전이의 핵심.

## C. hover 액션 바
- 리스트 항목·코멘트·업무 카드에 hover → **우상단에 액션 바** 노출(150ms fade).
- 아이콘 순서 고정: `리액션` `스레드/답글` `저장` `⋯ 더보기`. Slack과 동일 순서·동일 위치.
- 키보드 포커스 시에도 동일하게 노출(접근성).

## D. 자동완성 트리거
- `@` → 사람 멘션 / `:` → 이모지 / `#` → 프로젝트
- **컴포저·코멘트·캔버스 텍스트 블록에서 모두 동일하게 동작.** 한 곳만 되는 상태 금지.
- 팝업 조작: ↑↓ 이동, Enter 선택, Esc 취소. 입력 2글자부터 필터링.

## E. 링크 언퍼
- 붙여넣은 링크를 카드로 확장.
- 외부: **Figma**(썸네일·파일명), Notion(제목·아이콘), GitHub(레포·PR 상태).
- **내부 링크 언퍼**(업무·결정·프로젝트 URL): 제목 + 상태 칩 + 담당 아바타 + 진척%. Jira/Linear 언퍼 패턴.
- 언퍼 실패 시 원본 링크 텍스트 유지(깨진 카드 금지).

## F. 읽음 / 안읽음
- 안읽음 = **제목 굵게 + 좌측 코랄 점**. 읽음 = 일반 굵기, 점 제거.
- 목록에 **"여기까지 읽음" 구분선**(얇은 코랄 라인 + 우측 라벨). 새로 들어온 항목은 그 아래.
- Esc 또는 목록 이탈 시 읽음 처리.

## G. 용어 정렬 (라벨만 변경, 데이터 변경 없음)
| 현재 | 변경 후 | 적용 위치 |
|---|---|---|
| 알림 | **활동** | 사이드바·페이지 제목·헤더 |
| 저장 | **저장됨** | 사이드바·액션바 툴팁 |

- 라우트는 `/activity`, `/saved`로 정리(기존 경로는 리다이렉트).

## H. 전이 검증 (QA 항목 — 보고서에 결과 포함)
Slack만 써본 사람이 **설명 없이** 다음을 수행할 수 있는지 실제 테스트:
1. ⌘K로 특정 프로젝트 이동  2. 답글을 스레드로 작성  3. hover로 이모지 리액션
4. @로 동료 멘션  5. 활동에서 멘션만 필터  6. 항목 저장 후 다시 찾기

## 제약
- 시각 토큰 변경 금지(코랄·차콜 유지). Slack 색을 가져오지 말 것.
- 브라우저 기본 동작을 가로채는 단축키는 ⌘F뿐. 그 외 가로채기 금지.
- 포커스 링 유지, 대비 4.5:1, reduced-motion 시 패널 슬라이드·fade 제거하고 즉시 표시.
