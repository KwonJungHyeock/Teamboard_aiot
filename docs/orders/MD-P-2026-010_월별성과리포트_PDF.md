**월별 PDF로 내려받아 개인 성과 정리에 쓰게** 한다. 팀 피드백 원문: "월별 pdf다운을 통해서 개인 성과정리 편의성 제공"

## A. 화면 (미리보기 → 인쇄)
상단 컨트롤 바:
- `‹ 2026년 8월 ›` 월 선택 (미래 월 선택 불가)
- 대상 세그먼트 `[팀] [개인]` — 개인 선택 시 본인 기준. 팀장은 팀원 선택 드롭다운 추가 노출
- 우측 [PDF로 저장] 버튼

본문 = **실제 리포트를 화면에 그대로 렌더**(WYSIWYG). 미리보기와 출력물이 달라지면 안 됨.

## B. 출력 방식 (1차 확정)
- **브라우저 인쇄 기반**: `window.print()` + `@media print` CSS. 서버 PDF 렌더링 라이브러리 도입 금지.
  - 이유: Vercel 서버리스에서 headless Chromium은 용량·콜드스타트 제약이 크고, 한글 폰트 임베딩 시 배포 불안정.
  - 인쇄 CSS: `@page { size: A4; margin: 18mm 16mm 16mm; }`, 컨트롤 바·사이드바 `display:none`,
    표·카드에 `break-inside: avoid`, 배경 인쇄 위해 `print-color-adjust: exact`.
- 화면에 안내 한 줄: "인쇄 대화상자에서 '대상 → PDF로 저장'을 선택하세요. 배경 그래픽 켜기 권장."
- (2차 과제로 남김: 서버 생성 PDF는 메일 발송·자동 보관이 필요해질 때 별도 검토)

## C. 리포트 구성 (순서 고정)
1. **표지 블록** — 로고(다크 심볼) + "2026년 8월 성과 리포트" + 대상(팀/이름) + 생성일 + 문서번호 `MD-M-2026-08`
2. **요약** — 이번 달 한눈에: 완료 업무 건수 / 진행 중 건수 / 목표 평균 진척(전월 대비 증감) / 확정 결정 건수
3. **목표 달성 현황** — 연간 → 분기 → 월 순. 각 목표별 제목·상태칩·진척바·%(전월 대비 증감 표시)
4. **완료한 업무** — 영역별 그룹. `#ID · 제목 · 담당 · 완료일`
5. **진행 중 / 이월** — 진척%와 함께. 다음 달로 넘어가는 업무 명시
6. **확정된 결정** — 결정 로그에서 해당 월. `결정 내용 · 결정자 · 일자`. 번복분은 제외하고 최신 결정만
7. **다음 달 예정** — 다음 달 시작 예정 업무 목록
