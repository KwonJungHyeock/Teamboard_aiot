# MD-P-2026-032 §A3 — 귀속 대상 목록 (실행 전 제출 · 읽기 전용 조사)

프로젝트 없는 활성 업무 **19건**. 로컬 시드 기준.

> ⚠ **이 표는 마이그레이션 직전(배치 ③ 실행 전)의 스냅샷이다. 다시 생성하지 말 것.**
> 지금 다시 돌리면 0건이 나온다 — 19건 전부 자기 영역의 상시 프로젝트로 갔기 때문이다.
> 이 표의 값은 **옮겨진 뒤**에 있다: 「추정 프로젝트」와 「따르면 영역도 바뀐다」를 보고
> §B 완료 후 사람이 화면에서 옮길 때 쓴다. 그때 필요한 것이 **옮기기 전의 모습**이다.

> **이 표는 실행 목록이 아니라 §B 완료 후 사람이 보고 판단할 목록이다.**
>
> 마이그레이션(배치 ③)은 **19건 전부를 자기 영역의 상시 프로젝트로** 보낸다.
> 「추정 프로젝트」는 **실행하지 않는다** — 추정만으로 프로젝트와 영역 둘을 한 번에
> 바꾸면 되돌리기 어렵고, 틀렸을 때 어디까지 되돌려야 하는지가 흐려진다.
>
> §B 가 하려는 일이 바로 그 이동을 3초로 만드는 것이다 — 프로젝트 버튼 하나를 누르면
> 영역·목표가 따라온다. **사람이 화면에서 하는 것이 더 정확하고 더 빠르다.**
> 그때 「추정 프로젝트」와 「따르면 영역도 바뀐다」 두 열이 값을 한다.
