# 시안 (design)

디자인 시안 HTML·목업을 둔다. 구현 코드는 여기 두지 않는다.

## 규칙

- 시안 파일명에 문서번호를 붙인다 — `MD-P-2026-019_핵심3화면.html`
- 대체된 시안은 지우지 말고 `docs/archive/` 로 옮긴다.
- 지시서가 리포지토리 밖 시안 경로를 가리키면, 진행 전에 그 사실을 보고한다 (`docs/README.md` §1).

## 이 폴더에는 현행 시안만 둔다

구버전 시안은 `docs/archive/` 로 보낸다. 현행 디자인 기준은 MD-P-2026-019/020 규격(중성 톤)이다.
